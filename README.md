# codealpha_tasks2

This project is a basic *calculator application* developed as part of the CodeAlpha frontend tasks.

## Description

A simple, user-friendly calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features

- Interactive UI with buttons for digits and operations
- Real-time calculation display
- Responsive design for mobile and desktop
- Error handling for invalid inputs
- supports basic arithmetic operations
